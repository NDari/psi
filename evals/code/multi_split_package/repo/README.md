# notes tools

Small helpers for a folder of plain-text notes.

- `textkit.py`: text utilities (normalizing, wrapping and tables, word
  statistics, a tiny template engine).
- `report.py`: builds a report over a directory of `.txt` notes.
- `app.py`: the command line front end (`python3 app.py` prints usage).

Run the tests with `python3 -m unittest discover tests`.

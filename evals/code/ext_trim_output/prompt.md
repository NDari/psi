Write a psi extension, `.psi/extensions/trim_output/init.lua`, that trims long bash output, because it wastes context. When a `bash` tool result has more than `max_lines` lines, replace its text with its first 10 lines, then the line `[... N lines trimmed ...]`, then its last 10 lines, where N is the number of lines left out. Error results are trimmed the same way and stay errors. Results of other tools, and bash results of `max_lines` lines or fewer, are left alone. `max_lines` is a flag of the extension, default 40, which the user changes with `psi --ext-flag max_lines=100`. Check it with `psi ext check` and test it with `psi ext test`.

Write a psi extension, `.psi/extensions/bookmarks/init.lua`. Give the model a tool `bookmark` with the arguments `action` (required: `add`, `remove` or `list`), `name` (a string) and `note` (a string). Keep the bookmarks in the session so they follow the branch the user is on: after each change, append a session entry of type `bookmarks` whose data is `{ marks = { <name> = <note>, ... } }`, the whole set; the current bookmarks are those in the last such entry on the branch, or none when there is none. `add` stores name -> note (replacing an existing one) and returns `added <name>`; without both name and note it is an error result `add needs name and note`. `remove` deletes the bookmark and returns `removed <name>`, or an error result `no bookmark <name>` when there is none. `list` returns one line per bookmark, `<name>: <note>`, sorted by name, or `no bookmarks`. Also add a command `/bookmarks` that shows the same text as `list` as a notification. Check it with `psi ext check` and test it with `psi ext test`.

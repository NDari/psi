Write a psi extension, `.psi/extensions/todo_scan/init.lua`, that gives the model a read-only tool, also named `todo_scan`, for finding TODO comments. Its arguments: `glob` (a string, required: which files to scan, relative to the working directory, such as `**/*.py`; `*` matches within one path segment and `**/` matches zero or more directories) and `limit` (an integer, optional, default 50: the most matches to list). It reads each matching file and finds the lines that contain `TODO`. The result is one line per match, `path:line: text`, with the path relative to the working directory, line numbers counted from 1 and the line's text with surrounding whitespace stripped, ordered by path and then line. When there are more matches than `limit`, only the first `limit` are listed, followed by a last line `(N more)`. With no matches at all the result is `no TODOs`. Files that contain a NUL byte (binary files) are skipped. Check it with `psi ext check` and test it with `psi ext test`.

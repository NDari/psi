Write a psi extension, `.psi/extensions/lockfile_guard/init.lua`, that stops the model from writing or editing lockfiles by hand. Block any `write` or `edit` tool call whose path's file name is `go.sum` or `package-lock.json`, or ends in `.lock`. The block reason must be `lockfiles are generated, not edited: <path>`, with the path exactly as the call gave it. Every other call, including reads of lockfiles, goes through untouched. Check it with `psi ext check` and test it with `psi ext test`.
